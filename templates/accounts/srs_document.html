2. Introduction

2.1 System Overview

CourseCart is a Django-based web application that connects unemployed Tanzanian youth with skilled vocational instructors. The platform enables students to browse, enroll in, and complete affordable vocational courses in trades such as Plumbing, Electrical Installation, Tailoring, Carpentry, and Welding. Instructors can create and manage courses, upload multimedia lessons, and track student progress. The system includes simulated mobile money payment processing, automated certificate issuance, and a comprehensive notification system. The platform is deployed on PythonAnywhere cloud hosting with version control managed via GitHub.

2.2 Business Need

Tanzania faces a critical youth unemployment challenge with over 800,000 young people entering the labor market annually. Vocational training centers (VETA) can only accommodate approximately 30% of applicants due to physical capacity constraints. Traditional vocational courses cost between TZS 300,000 and 800,000, making them unaffordable for most unemployed youth. Furthermore, over 70% of training centers are concentrated in urban areas, leaving rural youth without access.

Simultaneously, Tanzania has experienced rapid digital growth:

  • Mobile phone penetration reached 89% (TCRA 2024)
  • Smartphone ownership among youth is at 78%
  • Mobile money transactions exceed TZS 190 trillion annually (Bank of Tanzania 2025)
  • Internet users exceed 35 million (TCRA 2024)

CourseCart bridges this gap by delivering affordable vocational training at TZS 20,000 to 50,000 through a mobile-responsive web platform accessible from any internet-connected device.

2.4 Scope

In Scope:

  • User registration with role-based access for Student, Instructor, and Administrator
  • Course catalogue with search, category filtering, and level filtering
  • Course enrollment with duplicate prevention
  • Simulated payment processing supporting Mobile Money, Bank Card, and Cash
  • Multi-format lesson delivery (YouTube videos, PDF documents, uploaded videos, text notes)
  • Progress tracking with completion percentage
  • Automated certificate issuance upon 100% completion
  • Notification system with real-time badge updates
  • Responsive web design for all devices

Out of Scope:

  • Real financial transactions (simulation only in Phase 1)
  • Native mobile applications (iOS/Android)
  • Multi-currency support (TZS only)
  • AI-powered course recommendations
  • Live video streaming
  • Multi-language support (English only; Swahili planned for Phase 2)
  • Integration with government certification bodies (VETA/NACTE)
  • Offline content access

2.5 System Context

CourseCart operates within the Tanzanian digital ecosystem, interfacing with:

  • Students: Unemployed youth accessing courses via web browsers
  • Instructors: Skilled professionals creating and managing courses
  • Administrators: Platform managers using the Django admin panel
  • Payment Gateways (Future): Integration with M-Pesa, Tigo Pesa, and bank APIs
  • Email Services (Future): SMTP servers for email notifications
  • Cloud Hosting: PythonAnywhere for production deployment
  • Version Control: GitHub for source code management

5. System Architecture

5.1 Architectural Overview

CourseCart follows the Django MTV (Model-Template-View) architectural pattern with a modular application structure. The system is organized into five main Django applications, each responsible for a specific business domain.

The architecture follows a three-tier structure:

  • Presentation Layer: HTML templates with vanilla CSS and JavaScript
  • Business Logic Layer: Django views and services
  • Data Layer: Django ORM with SQLite (development) / PostgreSQL (production)

8.1 Assumptions

  • Users have access to internet-connected devices (smartphones, tablets, or computers)
  • Users possess valid email addresses for registration
  • Instructors have verified vocational expertise in their chosen field
  • Mobile money services (M-Pesa, Tigo Pesa) remain operational in Tanzania
  • PythonAnywhere continues to support Django hosting
  • Users have basic digital literacy to navigate web applications
